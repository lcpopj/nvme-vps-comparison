## 关于"NVMe"和"SSD"的实际差别

不是所有人都需要 NVMe。如果你只是跑一个访问量不大的 WordPress、做个代理节点、挂个小机器人，传统 SATA SSD RAID-10 的随机 I/O 已经够用，4K 随机读写通常在几千 IOPS 量级，瓶颈在网络而不是磁盘。

NVMe 真正有意义的场景是：

- 跑 MySQL / PostgreSQL / Redis 等数据库，随机读写密集
- 高并发小文件场景，比如图片缩略图、日志处理
- 编译、容器启动等需要大量临时文件读写的任务
- 对 P99 延迟敏感的 API 服务

NVMe 的 4K 随机读写能到几万甚至十几万 IOPS，比 SATA SSD 高一个数量级，瓶颈会从磁盘转移到 CPU 和网络。如果你的工作负载里磁盘不是瓶颈，多花一倍钱追 NVMe 意义不大，不如把预算投到更好的线路上。
